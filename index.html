🎬 Authorized Video Downloader

Use GitHub Actions to download media you own or are authorized to save. No local Python installation is needed.

Important: This tool cannot bypass Cloudflare or other anti-bot protections, paywalls, sign-in requirements, or DRM. It cannot decrypt protected streams or extract keys.

How to use

  1. Open the workflow and click Run workflow.
  2. Enter an authorized, non-DRM video URL and choose a format.
  3. When successful, download the video-download artifact.
  4. If it fails, download video-diagnostics and read REPORT.md.
About NEPU's previous error: The GitHub runner received HTTP 403 from Cloudflare before yt-dlp could inspect the video. This is a source-side access block, not a format-selection problem. The workflow now labels this clearly; it will not try to evade the block.
