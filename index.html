🎬 Authorized Video Downloader

Download media you own or are authorized to save using a GitHub-hosted workflow. No local Python installation is needed.

DRM restriction: This tool cannot decrypt protected streams, extract keys, bypass access controls, or download DRM-protected NEPU movies.

How to use

  1. Open the workflow below.
  2. Click Run workflow.
  3. Paste an authorized, non-DRM URL and select a format.
  4. When the run completes, open its summary and download the video-download artifact.
